lr0
0.01 → 0.001
Learning rate khởi đầu giảm 10×
Phù hợp với fine-tune pretrained backbone (ImageNet). Stage 1 dùng freeze_lr riêng.
bảo vệ backbone
ít catastrophic forgetting
 lr0=0.01 quá cao cho fine-tuning: phá vỡ features pretrained đã học từ ImageNet. Catastrophic forgetting làm mất đặc trưng low-level (edge, texture) mà backbone đã học.
2026-06-24
cos_lr
False → True (default)
Cosine Annealing LR schedule bật mặc định
LR decay theo hàm cosine từ lr0 về lr0×lrf, thay vì linear/step decay.
smooth convergence
ít bị stuck local minima
 Cosine decay không về 0 đột ngột → model có cơ hội dao động nhẹ quanh vùng loss thấp để tìm sharp minimum. Step decay tạo gradient shock ở điểm drop.
2026-06-24
warmup_epochs
(ẩn) → 3 (exposed)
Warmup epochs expose ra UI
Tăng LR từ 0 → lr0 trong 3 epoch đầu. Expose ra UI cùng với momentum, weight_decay.
stable early training
tránh diverge epoch 1-3
 AdamW variance không ổn định trong 100-1000 iteration đầu (denominator nhỏ → effective LR lớn bất thường). Warmup giữ update magnitude nhỏ cho đến khi variance estimate ổn định.

label_smoothing
0.0 → 0.1
Nhãn mềm: phân phối (1-ε) cho đúng + ε/(K-1) cho sai
Thay hard label [0,1] bằng soft label [0.01, 0.99…]. Giảm overconfidence của output.
+generalization
model calibration tốt hơn
 Hard label khuyến khích model push logit → ∞ để minimize cross-entropy → overconfident với data ngoài distribution (ảnh mờ, đêm). Soft label đặt trần confidence thực tế.
2026-06-24
mixup
0.0 → 0.15
Blend 2 ảnh ngẫu nhiên: img = λ·img₁ + (1-λ)·img₂
Nhãn cũng blend theo λ. Chỉ áp dụng cho stage 2 / 1-stage (không áp dụng freeze stage).
+1–3% mAP
với dataset < 10k ảnh
 Tạo feature space liên tục giữa các class → model học decision boundary mịn hơn. Đặc biệt hiệu quả khi ảnh parking ban ngày/đêm có visual overlap.
2026-06-24
copy_paste
0.0 → 0.1
Copy object từ ảnh A, dán vào ảnh B với mask
Tăng tần suất xuất hiện của object nhỏ hoặc bị che trong batch.
+recall small obj
biển số bị che khuất
 Class imbalance spatial: biển số chiếm <2% diện tích ảnh, model không thấy đủ mẫu mỗi batch. Copy-paste nhân tần suất mà không cần thu thập thêm data.

degrees

Random rotation ±10° khi augment
Kết hợp với shear=2° (giữ mặc định YOLO). Expose ra UI để tuning.
rotation invariant
camera lắp nghiêng 0–15°
 Camera bãi đỗ xe lắp với góc nghiêng thực tế 5–20° tùy vị trí. Model không được train với góc nghiêng sẽ miss detection khi deploy camera mới.

cls
0.5 (YOLO default) → 1.5
Tăng trọng số Classification loss ×3
Total loss = box_loss + dfl_loss + cls×cls_loss. Cân bằng cho multi-class detection.
better class precision
phân biệt xe/biển số tốt hơn
 YOLO mặc định ưu tiên bbox regression (dfl+box loss). Với 6 class (car/moto/bus/truck/bicycle/plate), cls loss thấp → nhầm class → nhận dạng biển số sai loại phương tiện.

2-Stage Training
Tính năng mới
Stage 1: Freeze backbone → Stage 2: Full fine-tune
Stage 1: freeze=10 layers, lr=0.001, ~30 epochs — chỉ train detection head.
Stage 2: freeze=0, lr=lr0, main epochs — fine-tune toàn bộ + augmentation mạnh.
+2–5% mAP
so với 1-stage cùng epochs
 Catastrophic forgetting: nếu fine-tune toàn bộ ngay từ đầu với lr cao, backbone mất features đã học từ pretrained (ImageNet). Freeze stage 1 cho head hội tụ trước, Stage 2 tinh chỉnh toàn bộ với LR thấp (như Colab code đính kèm).
