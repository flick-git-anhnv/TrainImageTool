Avalonia Migration từ WinForms: Pitfall và Pattern Bắt Buộc

migration winforms avalonia mvvm binding severity: high project: iPGSv4
1 · Thread / Dispatcher
WinForms (SAI)
this.Invoke(() => label.Text = value)
Avalonia (ĐÚNG)
Dispatcher.UIThread.Post(() => label.Content = value)
⚠ Control.Invoke không tồn tại trong Avalonia — luôn dùng Dispatcher.UIThread.
2 · Binding — Bắt buộc INotifyPropertyChanged
// ViewModel bắt buộc implement INPC:
public class MyViewModel : ReactiveObject
{
    private string _name;
    public string Name
    {
        get => _name;
        set => this.RaiseAndSetIfChanged(ref _name, value);
    }
}
⚠ Binding không cập nhật UI nếu ViewModel thiếu INPC — lỗi âm thầm, khó debug.
3 · MessageBox → MsBox.Avalonia
WinForms (không có)
MessageBox.Show("msg")
Avalonia (ĐÚNG)
await MessageBoxManager.GetMessageBoxStandard("T","M").ShowAsync()

Tích Hợp SDK Milesight: Cấu Hình, Port, Channel

milesight sdk camera rtsp lpr severity: high project: iPGSv4
1 · Port và Channel — dùng kiểu số (int), không dùng string
SAI — silent error
camera.Port = "554"; camera.Channel = "1";
ĐÚNG
camera.Port = 554; camera.Channel = 1;
// UI input → phải parse/validate trước:
if (!int.TryParse(txtPort.Text, out int port))
{
    ShowError("Port phải là số nguyên");
    return;
}
camera.Port = port;
2 · HTTP Port ≠ RTSP Port
HTTP Port (config SDK)
Mặc định 80 — dùng khi khởi tạo MilesightCameraConfig
RTSP Port (stream)
Mặc định 554 — riêng biệt, dùng trong URL stream
⚠ Đây là lỗi phổ biến nhất — nhầm HTTP port (80) với RTSP port (554) làm stream không kết nối được.
3 · RTSP URL Format
rtsp://{username}:{password}@{ip}:{rtsp_port}/main
rtsp://{username}:{password}@{ip}:{rtsp_port}/sub

// Ví dụ:
rtsp://admin:password@192.168.1.100:554/main
⚠ Credentials có ký tự đặc biệt phải URL-encode trước khi đưa vào RTSP URL.
4 · Channel bắt đầu từ 1 (không phải 0)
SAI
Channel = 0 → stream NULL, không báo lỗi
ĐÚNG
Channel = 1 (1-based index)
5 · Reconnect Loop
private async Task StartWithReconnect(CancellationToken ct)
{
    while (!ct.IsCancellationRequested)
    {
        try
        {
            await _camera.ConnectAsync();
            await _camera.StartStreamAsync();
            await WaitForDisconnectAsync(ct);
        }
        catch (Exception ex)
        {
            _logger.LogWarning("Camera disconnected: {msg}", ex.Message);
            await Task.Delay(5000, ct); // Chờ 5s rồi reconnect
        }
    }
}
